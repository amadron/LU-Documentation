# Building and Properties Guide

[Game Guide](./README.md) | [Getting Started](./Getting%20Started.md) | [Worlds](./Worlds%20Guide.md) | [Items](./Item%20Guide.md)

Building takes several forms: a **Quick Build** assembles an object during
an activity, a **modular build** combines parts such as rocket pieces, and a
**property** is a place to arrange models and make creations. Follow your
client's prompts; the availability and behavior of each feature depend on
the server.

## Start a property

The original 2010 guide describes a first property area, Block Yard, reached
from Avant Gardens. It presents a Maelstrom encounter followed by property
tutorials. Later property areas in that guide are Nimbus Rock, Chantey
Shanty, and Raven Bluff, with earlier property challenges unlocking later
ones. This is a historical progression, not a guarantee of current access.

1. Look for an available property launch point and talk to its guide or guard.
2. Follow the active mission and resolve any required encounter.
3. Complete the placement tutorial if offered.
4. Check whether your server saves your property and supports the features
   you want to use before investing significant time.

The [quest location index](./quests/locations/README.md) lists property zones
and associated definitions. A listed zone does not prove that the property
or its encounters are enabled.

## Place and build

- Open the model section of your inventory and select an available model.
- Use the client's building controls to position or rotate it, then confirm
  placement. The historical guide describes a Shift prompt, but controls can
  differ; follow what your client displays.
- Try editing, picking up, and placing a small model again before making a
  larger project. Save when the interface offers the option.
- Use the in-game tutorial to learn which bricks and tools are available.

Models, bricks, and other building items have different roles. If something
cannot be placed, check its type and whether you are in an editable area.
See the [Item Guide](./Item%20Guide.md) for inventory checks.

## Try behaviors

The original guide describes attaching behaviors to models to trigger
actions such as movement, rotation, or sound. Start with one simple action,
test it, then add more only if it works. Specific behaviors, persistence,
and interactions may be unsupported or changed in your deployment.

## If something does not work

Check that the property is claimed, the correct mission is active, and the
object is a placeable model. If access, saving, or behavior editing still
fails, report the property name, the step attempted, and any message to the
server's staff. Do not assume a historical unlock sequence is implemented.

## Source and limitations

Building concepts, historical property progression, and basic model editing
are summarized from the user-provided *LEGO Universe Official Game Guide*
(2010), pp. 12 and 165–169. The guide is historical; server support is not
verified merely because the original game offered a feature.
