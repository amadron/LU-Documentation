# LEGO Universe Game Guide

Welcome! This folder is organized around what you may want to do in the game:
explore worlds, follow missions, collect and use items, race, and tame pets.
Start with one of the practical guides below; the larger databases are there
when you need to look up a particular name, reward, or location.

## Quick catalogs

- [Flat item list](../LEGO%20Universe%20Item%20List.md) — one searchable table of item names and basic fields. For source details, use the [item database](./items/README.md).
- [NPC and creature template list](../LEGO%20Universe%20NPC%20List.md) — a broad list of registered character and creature templates, not a live map of where NPCs currently stand. For quest-related characters, use the [quest NPC index](./quests/NPC%20Index.md).
- [Quest-related zones and locations](./quests/locations/README.md)
- [Item-source locations](./items/locations/README.md)

The flat lists are useful for quick searches but are not replacements for
the richer databases. The NPC catalog covers many templates that have no quest
association; the quest NPC index is narrower and focuses on characters linked
to missions and achievements.

## Reading the information

The guides explain common ways to play, but each DarkflameServer deployment
may enable different content. A record in a database means that a definition
exists in the supplied files; it does not guarantee that the activity, item,
pet, or character is available in your game. A mapped location is a place
recorded in a map file, not proof that something is currently spawned there.
Historical community notes are labeled separately from local data.

For staff and server administrators, see the [Gamemaster Guide](../server/DarkflameServer%20Gamemaster%20Guide.md)
and [technical server documentation](../server/README.md).

This is a normal Markdown folder that can be browsed in GitLab; it does not
automatically create or publish a separate GitLab Wiki.
